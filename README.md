# Sign-up Form

## The goal of this project is to a sign-up form using a design template based on HTML/CSS fundamentals and simple UI design structure. The following topics were implemented during the project: 

- HTML – using elements like `<main>`, `<section>`, `<form>` and more
- CSS Fundamentals – styling with custom fonts, spacing, colors, and transitions
- Flexbox – used to align navigation, structure the layout etc.
- Box Model – white space, full-width sections, padding/margin and `box-sizing`
- Form Validation and Styling – a styled email subscription with simple hover interaction.
